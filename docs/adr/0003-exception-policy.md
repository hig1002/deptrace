# 0003. 예외는 사유와 만료일이 있어야만 인정한다

- 상태: 채택 (2026-10-19)

## 맥락

수정 버전이 없거나 현재 플랫폼 라인으로는 받을 수 없는 권고가 남는다. 경매톡의 경우는 Spring Framework 7.0에서만 수정된 권고 3건과 querydsl 1건이었다. 게이트를 계속 실패로 두면 경고가 무시되고, 영구 무시 목록을 두면 판단 근거가 사라진다.

## 결정

- 예외 항목에는 `id`(GHSA 또는 CVE), 선택 항목 `package`, 필수 항목 `reason`·`expires`를 둔다.
- 사유나 만료일이 없으면 설정 오류로 실패시키고, 만료일이 지나면 다시 위반으로 되돌린다.
- `package`를 지정하면 같은 ID라도 다른 모듈의 권고는 인정하지 않는다.

## 근거

- 예외는 "지금 영향이 없다"는 판단이지 "앞으로도 없다"는 판단이 아니다. 코드가 바뀌면 근거가 무효가 되므로 다시 볼 시점이 필요하다.
- 사유에는 확인 방법을 남긴다. 예: "SseEmitter·ServerSentEvent 사용 없음, src/main 검색 0건". 그래야 다음 검토자가 같은 확인을 재현할 수 있다.
